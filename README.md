# Hermes Agent — OAuth brand pages

This repository exists for exactly one reason: to host the **app homepage** and
**privacy policy** that Google requires before a private OAuth client can be
switched from *Testing* to *In production* publishing status.

- **App name:** Hermes Agent
- **What it is:** a private, single-user personal automation running on its
  owner's own machine. It is not distributed, not offered to the public, and
  has exactly one user — the owner of the Google Account that grants it access.
- **Privacy policy:** [PRIVACY.md](PRIVACY.md)
- **Contact:** the GitHub account hosting this repository
  ([@yanbing2026](https://github.com/yanbing2026))

There is no source code here and nothing to install. The actual tool lives
entirely on the owner's machine.
